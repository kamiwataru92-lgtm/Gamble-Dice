# Gacha Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** コインで引くガチャ（1連 1000／9連 8000）と、当たったアイテムをアイコンにして勝利時に BGM を流す仕組みを追加する。

**Architecture:** 抽選・購入は純粋関数（`src/gacha/`）でテストし、Firestore 側はトランザクションで適用するだけにする。アイテムは `catalog.ts` の配列に書き足すだけで増える。

**Tech Stack:** 既存と同じ（Vite + React + TS、Firebase、Vitest）

**Spec:** `docs/superpowers/specs/2026-11-23-gacha-design.md`

## Global Constraints
- 確率：common 0.6335, uncommon 0.25, rare 0.10, superRare 0.01, epic 0.005, legendary 0.001, mythic 0.0005
- 価格：1連 1000、9連 8000
- 9連保証：先頭 8 回にレア以上がなければ 9 回目はレア以上
- 空のレア度は、アイテムのある一つ下に繰り下げ
- BGM はスーパーレア以上のみ

## Review Focus
1. コイン不足での購入 → コインもアイテムも変わらない
2. rng が境界値（0、0.9999…）→ 範囲内のアイテムが出る
3. Epic 以上が空 → 例外にならずスーパーレアに繰り下げ
4. 既存ユーザー（`items` / `icon` フィールドなし）→ 0 個・アイコンなしとして扱う
5. 持っていないアイテムをアイコンにする → 拒否

### Task 1: 抽選と購入（純粋関数）
**Files:** Create `src/gacha/types.ts`, `src/gacha/config.ts`, `src/gacha/catalog.ts`, `src/gacha/draw.ts` ／ Test `tests/gacha.test.ts`

**Interfaces（Produces）:**
- `Rarity = 'common'|'uncommon'|'rare'|'superRare'|'epic'|'legendary'|'mythic'`、`RARITIES: Rarity[]`（低い順）
- `Item { id: string; rarity: Rarity; name: string; emoji?: string; image?: string; bgm?: string }`
- `RARITY_RATES: Record<Rarity, number>`、`PRICES: { 1: 1000, 9: 8000 }`
- `ITEMS: Item[]`
- `rollRarity(rng, minRarity?: Rarity): Rarity` — `minRarity` 以上だけで比率を正規化
- `drawItems(count: 1 | 9, rng, items = ITEMS): Item[]` — 保証・繰り下げ込み
- `purchase(wallet: { coins: number; items: Record<string, number> }, count: 1|9, rng, items = ITEMS): { coins; items; drawn: Item[] }` — コイン不足は `GameError('insufficient_coins')`
- `setIcon(owned: Record<string, number>, itemId: string | null): string | null` — 未所持は `GameError('not_owned')`

- [ ] テスト：境界 rng（0 → common、0.6335 → uncommon、0.99999 → mythic）、`minRarity='rare'` で rare 未満が出ない、9連で先頭 8 回が common になる rng でも 9 回目が rare 以上、epic 以上が空のカタログで epic を引くと superRare、購入でコインが減り所持数が増える、不足で例外かつ入力不変、`setIcon` 未所持で例外・null は許可、カタログの id 重複なし・BGM はスーパーレア以上のみ
- [ ] RED を確認 → 実装 → GREEN → commit `feat: add gacha draw and purchase logic`
