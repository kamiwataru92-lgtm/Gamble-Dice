# ガチャ 設計書

日付: 2026-11-23 ／ 本体: `2026-11-23-gamble-dice-design.md`

## 目的
コインの使い道（インフレ対策）として、絵文字やミームキャラが当たるガチャを追加する。当たったアイテムはアカウントに保存し、ほかのゲームとも共有できる形にする。

## ルール
- 1連 1000 コイン、9連 8000 コイン。9連なのは結果画面を 3×3 に収めるため
- 確率：コモン 63.35%、アンコモン 25%、レア 10%、スーパーレア 1%、Epic 0.5%、Legendary 0.1%、Mythic 0.05%
- 9連の保証：最初の 8 回にレア以上がなければ、9 回目はレア以上（レア以上の確率の比率で抽選）
- 同じアイテムは所持数が増える
- 当たったレア度にアイテムが 1 つもない場合は、アイテムのある一つ下のレア度に繰り下げる（※提案。Epic 以上が空のうちのため）

| レア度 | 中身 |
|---|---|
| コモン | ミーム性の弱い絵文字 |
| アンコモン | ミーム性が少しある絵文字 |
| レア | ミーム性の強い絵文字 |
| スーパーレア | 国旗（絵文字＋追加画像） |
| Epic | 知名度の低いミーム |
| Legendary | 知名度がそこそこのミーム |
| Mythic | 知名度が高い、または不謹慎なミーム |

- 今回登録するのは絵文字だけ（コモン〜スーパーレア）。Epic 以上と BGM・画像は利用者が `src/gacha/catalog.ts` に追加する
- スーパーレア以上は BGM を持てる（※提案）

## 使い方
- 持っているアイテムを 1 つ「アイコン」に設定し、部屋の名前の横に表示する
- 総取りで勝った人のアイコンに BGM があれば、結果画面で全員の端末で再生する（自動再生できない端末では再生ボタンを出す）

## 作り
- Spark プランのまま、抽選はクライアントで行う（友達同士の前提。ズル対策は非ゴール）
- `users/{uid}` に `items: { [itemId]: 所持数 }` と `icon: itemId | null` を追加。購入はコインの減算と所持数の加算を 1 トランザクションで行う
- 部屋の `PlayerState` に参加時点の `icon` を記録する
- 画像・音は `public/items/` に置き、カタログから参照する
